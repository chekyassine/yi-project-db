# Hosting

- This project is hosted on Cloudflare Pages (migrated away from Netlify due to limits).
- The project is a static site. Deployment is automatic on pushes to the `main` branch.
- Do NOT use Netlify instructions or write Netlify specific configurations (`netlify.toml`).
- Do NOT run a build step for this project since it's just raw HTML/JS/CSS.
